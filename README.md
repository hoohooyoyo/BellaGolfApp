# Bella Golf App

一个用于高尔夫数据录入和统计分析的现代Web应用。

## 功能特点

- **18洞数据录入**：记录每洞的挥杆、切杆和推杆数据
- **全面统计分析**：
  - 概况：成绩、推杆、罚杆、标杆上果岭率等
  - 开球：球道率、方向分析、距离统计
  - 铁杆：各距离段上果岭率和精准度
  - 切杆：救球成功率和平均剩余距离
  - 推杆：推进概率和三推分析
- **现代化界面**：响应式设计，高尔夫主题配色
- **本地运行**：无需服务器，直接在浏览器中使用

## 使用方法

1. 下载本项目
2. 用浏览器打开 `index.html` 文件
3. 在"球洞录入"标签页中输入每洞的数据
4. 在"统计概览"标签页中查看分析结果
